# PR 본문 템플릿 (한국어)

`create-pr` 스킬이 인자 없이 실행되었을 때 쓰는 기본 템플릿이다. 영어 버전은 `pr-template.en.md`를 본다.

채울 때 `<!-- -->` 주석은 제거하고, 해당 사항이 없는 섹션은 "없음"으로 적거나 생략한다.

```markdown
## 요약

<!-- 이 PR이 무엇을 바꾸고 왜 바꾸는지 2~3문장으로 쓴다. -->

## 변경 사항

<!-- 주요 변경을 항목으로 나열한다. 파일 목록 나열보다 동작 변화를 우선한다. -->
- 

## 검증

<!-- 실제로 통과한 항목만 체크한다. -->
- [ ] `bun run lint`
- [ ] `bun run test`
- [ ] `bun run build`

## 참고

<!-- 리뷰어가 알아야 할 점, 후속 작업, 알려진 한계. 없으면 "없음". -->

---

🤖 Generated with [Claude Code](https://claude.com/claude-code)
```
